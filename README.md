# Beyond Major Floods, project page

Project page for "Beyond Major Floods: Deep Learning for Detecting Shallow Water Inundation in Agricultural Areas" by Phongsakon Mark Konrad, Toygar Tanyel and Serkan Ayvaz, published at KES 2025 in Procedia Computer Science 270. The page is served at https://aiml-sdu.github.io/beyond-major-floods-page/.

This repository holds the built static page only. All plotted values come from Tables 1 and 2 of the paper.
